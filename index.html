About me

Hi, I'm Jomar Apelo, a fourth-year Computer Engineering student at ICCT. I got into engineering because I like understanding how a program ends up as something physical: a blinking LED, a sensor reading, a packet crossing a network.

Most of my school work sits between hardware and software. I've written firmware for microcontrollers, built web apps with databases behind them, and set up small networks in lab activities. My capstone and thesis work has also pushed me into applying machine learning ideas to practical problems.

Right now I'm looking for an internship or OJT where I can contribute to a team, get feedback from experienced engineers, and keep building.

Featured project

RETRIEVO: Intelligent Lost & Found Recovery Platform

RETRIEVO is an AI-assisted platform that helps people get lost items back. Instead of scrolling through hundreds of posts, a user reports what they lost, and the system ranks the most likely matches from reports of found items.

Key features

  • Matches lost and found reports using natural language processing
  • Similarity scoring so the best candidates appear first
  • Location and time analysis to rule out unlikely matches
  • Separate flows for reporting a lost item and a found item
  • Python
  • NLP
  • Cosine similarity
  • React
  • Flask
  • MySQL
